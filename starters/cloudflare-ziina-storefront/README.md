# AlyyConnect storefront starter (Next.js + Cloudflare + Ziina)

This is a documented skeleton, not a private client dump.

## Stack
- Next.js static export
- Tailwind CSS
- Cloudflare Pages or Workers static assets
- Ziina payment links
- WhatsApp lead CTA

## Do
- Keep checkout as a payment link until you need a full merchant API.
- Put secrets in Cloudflare, never in the repo.
- Ship JSON-LD for LocalBusiness or Product.

## Don’t
- Commit customer data.
- Pretend sample dashboard numbers are production KPIs.
